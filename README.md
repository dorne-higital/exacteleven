# Exact XI

Exact XI is a football lineup-guessing game where players try to recall the exact starting XI (and formation) fielded in a real Premier League match. It's built with Nuxt 4, Vue 3 and TypeScript, styled with SCSS, deployed to Cloudflare Pages, and linted with ESLint and Stylelint. This repo currently holds only the project scaffold; game logic and data land in later phases.

Requires Node 22+ (see `.nvmrc`).

## Getting started

```bash
yarn install
yarn dev
```

## Other scripts

```bash
yarn build       # production build
yarn test        # run the vitest test suite
yarn lint        # run eslint
yarn lint:style  # run stylelint
yarn typecheck   # run nuxt/vue-tsc type checking
```
